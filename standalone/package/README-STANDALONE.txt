GRIGLIA PCP - REPERTORY GRID STUDIO

Questa edizione funziona interamente in locale.

- Non richiede connessione Internet.
- Non richiede Python, Node.js o Streamlit.
- I dati restano nel browser del computer.
- I backup e i report vengono salvati solo quando richiesto dall'utente.

Per avviare l'app usare il collegamento "Griglia PCP".
Per rimuoverla usare "Disinstalla Griglia PCP" dal menu Start.
